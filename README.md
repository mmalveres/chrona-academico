# Chrona 🏗️

Sistema web completo para o gerenciamento e controle de obras de construção civil. O Chrona facilita o registro diário de atividades, controle financeiro, armazenamento de documentos e acompanhamento do cronograma físico-financeiro, centralizando as informações estratégicas da sua obra.

## 🚀 Funcionalidades Principais

* **Diário de Obras (RDO):** Registro detalhado das atividades diárias, efetivo de mão de obra, condições climáticas e ocorrências importantes.
* **Gestão Fotográfica:** Upload e organização de fotos do progresso da obra, vinculadas aos diários para um histórico visual completo.
* **Controle Financeiro:** Acompanhamento do orçamento previsto *versus* realizado e controle de despesas.
* **Gestão de Documentos e Projetos:** Armazenamento e organização centralizada de plantas, contratos, alvarás e outros documentos vitais.
* **Cronograma Físico:** Visualização e acompanhamento das etapas da obra e seus prazos.
* **Geração de Relatórios:** Emissão de relatórios consolidados para análise de desempenho e progresso da obra.
* **Controle de Acesso e Auditoria:** Níveis de permissão diferenciados (ex: Administrador, Engenheiro) e registro de ações (logs) para maior segurança.

## 🛠️ Tecnologias Utilizadas

* **Linguagem:** PHP
* **Banco de Dados:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Framework CSS:** Bootstrap 5
